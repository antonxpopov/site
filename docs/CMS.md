# Редактирование сайта через Pages CMS

Pages CMS (https://app.pagescms.org) — это визуальный редактор, который работает прямо с файлами репозитория
`antonxpopov/site` на GitHub. Каждое сохранение — это коммит в ветку; после него GitHub Actions пересобирает сайт
(обычно 2–4 минуты).

Войти: https://app.pagescms.org → «Sign in with GitHub» → выбрать репозиторий `site` и ветку `main`.

## Что можно редактировать

| Раздел в CMS | Что внутри | Где хранится |
| --- | --- | --- |
| Проекты и перформансы | все проекты: тексты EN/RU, фото, видео, аудио, зин, ссылки, скрытие с сайта | `src/cms/projects/<адрес>.json` |
| Лекции и мастер-классы | страница Teaching: тексты EN/RU, фото, YouTube | `src/cms/lectures/*.json` |
| Список перформансов | строки на странице Performances | `src/cms/performances.json` |
| Обо мне | короткая биография EN/RU (главная и About) | `src/cms/about.json` |
| Контакты | строки страницы Contacts (почта, телефон, соцсети…) | `src/cms/contacts.json` |
| Блог (EN) / Блог (RU) | записи блога (Markdown) | `src/content/blog/{en,ru}/*.md` |

Не редактируется через CMS (меняется в коде): CV-таблица на странице About, фото первого слайдера на главной,
тексты интерфейса (меню, кнопки), оформление.

## Типичные действия

**Изменить текст проекта.** Проекты и перформансы → выбрать проект → правьте «Текст — English» / «Текст — русский»
(абзацы разделяются пустой строкой) → Save.

**Заменить / добавить / переставить фото.** В проекте поле «Фото»: загрузите файл (имя —
`popov_<адрес>_<год>_01.jpg`, латиницей), порядок в списке = порядок в слайдере, первое фото — обложка.
Если в списке проектов нужна другая обложка, чем первое фото слайдера, заполните «Обложка для списков».
Загруженные файлы попадают в `src/assets/images/projects`; сайт сам делает AVIF/WebP нужных размеров.
Рекомендуется загружать JPG шириной 1800–2400 px.

**Добавить видео.** Vimeo: число из ссылки `vimeo.com/1095200572` → поле «Vimeo ID». YouTube — только если нет Vimeo.
Плеер подгружается по клику.

**Добавить аудио.** Файл mp3 загрузите в «Аудио» (папка `public/audio`), в проекте выберите его в поле «Аудио (mp3)».
Для красивой волны без загрузки файла запустите на компьютере `npm run peaks -- public/audio/<файл>.mp3`
и закоммитьте получившийся `.peaks.json` (без него волна рисуется, но mp3 грузится сразу). Лучше mp3 128 kbps.

**Зин Calameo.** Поле «Calameo (зин)»: код из ссылки `calameo.com/books/КОД`. Вместо слайдера покажется зин.

**Скрыть проект.** Включите «Скрыть с сайта» — проект остаётся в CMS, но исчезает с сайта.

**Новый проект.** Проекты и перформансы → New → «Адрес страницы» (латиница, дефис, потом не менять), раздел
(Проекты / Перформансы), год, название, тексты, фото. Порядок: новые годы сверху; внутри года — по числу «Порядок внутри года»
(1 — первым).

**Новая лекция.** Лекции и мастер-классы → New. Фото загружаются в `src/assets/images/education`.

**Блог.** Блог сейчас спрятан (`src/constants/blog.ts`, режим `unlisted`). Записи создаются в «Блог (EN)» и «Блог (RU)» с
одинаковым адресом; поле «Черновик» включено по умолчанию — снимите галочку, когда запись готова. Чтобы открыть блог для всех,
замените в `src/constants/blog.ts` `'unlisted'` на `'on'`.

## Если что-то пошло не так

- После сохранения сайт не обновился: проверьте вкладку Actions в репозитории — сборка могла упасть (красный крестик).
  Чаще всего причина — неверный формат файла фото или пустое обязательное поле.
- Русская версия показывает английский текст: поле «Название (RU)» в проекте пустое — заполните его.
- Любое изменение можно откатить: GitHub → History файла → Revert.
