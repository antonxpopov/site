# 🚀 Быстрый запуск

## Шаг 1: Установка зависимостей

```bash
npm install
```

## Шаг 2: Запуск проекта

```bash
npm run dev
```

После запуска откройте браузер и перейдите по адресу, который покажет Vite (обычно `http://localhost:5173`)

## 📝 Что дальше?

1. **Добавьте аудио файлы** в папку `public/audio/` (формат MP3)
2. **Отредактируйте проекты** в файле `src/data/projects.js`
3. **Измените контакты** в файле `src/components/Contacts.jsx`
4. **Обновите информацию "Обо мне"** в файле `src/components/About.jsx`
5. **Измените имя** в файле `src/components/Hero.jsx`

## 🌐 Деплой

Для деплоя на Vercel:

```bash
npm run build
vercel
```

Или подключите репозиторий GitHub к Vercel через веб-интерфейс.
